# Sonny
Sonny is a strategic action adventure game developed on Unreal Engine 5 in which you play as a robot who just become self aware. The gameplay features 2 main mechanics that are designed to test your skill and strategic thinking.

# Path Mode
In Path Mode, you have to draw a path to the platform with the same symbol. You can turn off drawing at any time to plan the right path.
At the same time, you have to avoid patrolling Supervisors or you will have to start all over again.

# Combat Mode
In Combat Mode, you have to reach the end of the arena. On your way, there are opponents who will chase you. If any of them catch you, you have to start all over again. 
To survive, you have a limited number of blocks that you can place in the arena. To eliminate your opponents, you have to trap them in a small area.

# Scores and Upgrades
When you complete the arena, you get points that you can use for upgrades. You get 1 point for each new score level gained. Before each new arena, you have a chance to play the previous levels one more time. 
This allows you to aim for a new score record and get new score levels after boosting yourself with upgrades.
